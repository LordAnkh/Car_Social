# Post Object Schema

## Overview
Posts are stored in the MongoDB `posts` collection. Each post is associated with a user and contains car-related content.

## Post Object Structure

```typescript
{
  _id: ObjectId,              // Auto-generated by MongoDB
  userId: string,             // User's MongoDB _id (from user_credentals collection)
  userEmail: string,          // User's email for display
  userName?: string,          // Optional: User's display name
  description: string,        // Post caption/description
  imageUrl: string,           // URL to the car image
  createdAt: Date,            // Timestamp when post was created
  updatedAt: Date,            // Timestamp when post was last modified
  likes: string[],            // Array of user IDs who liked the post
  likesCount: number,         // Total number of likes
  comments: Comment[],        // Array of comment objects
  commentsCount: number       // Total number of comments
}
```

## Comment Object Structure

```typescript
{
  commentId: string,          // Unique identifier for the comment
  userId: string,             // Commenter's user ID
  userEmail: string,          // Commenter's email
  userName?: string,          // Optional: Commenter's display name
  text: string,               // Comment content
  createdAt: Date             // Timestamp when comment was created
}
```

## Field Descriptions

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| _id | ObjectId | Yes (auto) | Unique identifier generated by MongoDB |
| userId | string | Yes | Reference to the user who created the post |
| userEmail | string | Yes | Email of the post creator |
| userName | string | No | Display name of the post creator |
| description | string | Yes | The post's caption/description |
| imageUrl | string | Yes | URL to the car image |
| createdAt | Date | Yes (auto) | ISO 8601 timestamp of creation |
| updatedAt | Date | Yes (auto) | ISO 8601 timestamp of last update |
| likes | string[] | Yes | Array of user IDs who liked the post |
| likesCount | number | Yes | Count of likes (for quick access) |
| comments | Comment[] | Yes | Array of comment objects |
| commentsCount | number | Yes | Count of comments (for quick access) |

## MongoDB Collection

- **Collection Name**: `posts`
- **Database**: `Car_Database`

## Notes

- All posts are public by default
- Posts are sorted by `createdAt` (newest first) when fetching
- User information (email, name) is duplicated in posts for performance (avoid joins)
- Consider adding indexes on `userId` and `createdAt` for faster queries
